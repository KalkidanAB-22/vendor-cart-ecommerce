# 🛒 Shop Lite - Full Stack E-Commerce Application


## 📌 Overview

Shop Lite is a full-stack e-commerce application built with React,
Tailwind CSS, Express.js, and PostgreSQL.

The project demonstrates a complete application flow:

Frontend → API → Database


Users can view products, search products, and interact with a modern responsive interface.

# ✨ Features

## Frontend

✅ Responsive product gallery  
✅ Product search  
✅ Modern UI with Tailwind CSS  
✅ Local product image handling  
✅ Component-based React structure  


## Backend

✅ REST API with Express.js  
✅ PostgreSQL database connection  
✅ Product fetching endpoint  
✅ Search filtering API  


## Database

✅ PostgreSQL  
✅ Product table  
✅ Cloud database with Supabase  



# 🛠️ Tech Stack

# ⚙️ Installation


## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/KalkidanAB-22/shop-lite-ecommerce.git
```

---

## Frontend Setup

```bash
cd shop-lite

npm install

npm run dev
```

---

## Backend Setup

```bash
cd server

npm install

npm start
```

---
